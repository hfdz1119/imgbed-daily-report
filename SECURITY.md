# Security Policy

## Supported versions

Security fixes are applied to the latest release of ImgBed Daily Report.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is enabled
for the repository. Do not open a public issue containing Bot Tokens, Chat IDs,
trigger tokens, database identifiers, private file metadata, or Worker logs
that contain sensitive configuration.

If private reporting is unavailable, open a public issue containing only a
high-level description and request a private contact channel.
